# ShikshaSutraa – Landing Page

A modern, fully responsive landing page for ShikshaSutraa, an ed-tech platform focused on practical, industry-relevant learning. The site highlights popular programs, mentors, student testimonials, and free masterclasses to drive enrollments.

## Tech Stack
- **React** – Component-based UI
- **Tailwind CSS** – Utility-first styling
- **Framer Motion** – Smooth animations & transitions

## Features
- Hero section with animated illustrations
- Program cards with pre-booking CTAs
- Testimonials carousel
- Fully responsive design
